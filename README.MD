# João Fotógrafo - Portfólio Profissional

## 📸 Sobre o Projeto

**João Fotógrafo** é um site fictício de portfólio desenvolvido para demonstrar as habilidades de um fotógrafo profissional especializado em casamentos, eventos e retratos. O site apresenta um layout elegante e moderno, com foco em showcasing de trabalhos fotográficos de alta qualidade.

---

## 🎯 Objetivo

Este projeto foi criado com os seguintes objetivos:

1. **Demonstrar Habilidades Web** - Aplicar conhecimentos de HTML5, CSS3 e design responsivo
2. **Criar um Portfólio Digital** - Apresentar trabalhos fotográficos de forma profissional e elegante
3. **Aprender Desenvolvimento Frontend** - Praticar conceitos de:
   - Estrutura semântica HTML
   - Estilização avançada com CSS
   - Responsividade para diferentes dispositivos
   - Animações e transições
   - User Experience (UX)

4. **Portfolio Inspirado em Referências Reais** - Estudo de caso baseado em sites profissionais de fotógrafos como referência de design

---

## 🎨 Características

✨ **Design Elegante e Minimalista**
- Paleta de cores: Preto, Branco e Ouro (#d4af37)
- Typography profissional com Google Fonts (Montserrat e Playfair Display)

📱 **Responsivo**
- Desktop, Tablet e Mobile
- Media queries para adaptação perfeita

🖼️ **Galeria de Fotos**
- Grid 3x3 com imagens profissionais
- Efeitos hover com zoom e overlay
- Formato retrato (celular)

🎬 **Animações**
- Fade-in no hero section
- Transições suaves em hover
- Parallax no background

📄 **Seções**
- **Hero** - Apresentação visual impactante
- **About** - Biografia do fotógrafo
- **Manifesto** - Filosofia e valores
- **Galeria** - Portfólio de trabalhos
- **CTA** - Call-to-action com contatos
- **Footer** - Links e informações

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e animações
- **Google Fonts** - Tipografia profissional
- **Unsplash/Pexels** - Imagens de alta qualidade
- **Vercel** - Deploy e hospedagem
